当前最新的设计

MemoryScheduler：后台定时任务进行记忆提取
作为组件根据应用启停
启动：
将处于memory_task表中running的任务变为pending，用于后续崩溃恢复
启动loop循环检测

停止：
将处于memory_task表中running的任务变为pending，用于后续崩溃恢复

循环中的几项任务：
1 记忆同步检测，30s一次
2 卡死回收 + 兜底扫描 + dead 指标 60s一次
3 命中刷回：Redis Hash 聚合 → 批量回写 MySQL → DEL，5分钟一次
4 每日定时登记：consolidate / decay_archive / sync_check / conflict_detect，60s一次
5 一直循环不停领取任务然后跑？什么任务，怎么不间隔跑？？
