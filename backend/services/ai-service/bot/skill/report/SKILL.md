# 分析报告生成技能

当用户需要生成数据分析报告时使用此技能。

## 可用工具

- **describe_table** / **describe_csv**: 了解数据来源
- **sample_rows**: 查看数据样例
- **describe_table_stats** / **describe_csv_stats**: 获取统计指标

## 分析流程

1. **明确报告目标和受众**  
   给谁看？技术人员、业务人员、还是管理层？不同受众结构完全不同。  
   目的是什么？汇报、决策支持、还是技术文档？

2. **收集信息**  
   调用 describe/sample/stats 工具获取数据背景。  
   如果用户已提供分析代码/图表结果，作为报告素材。

3. **确定报告结构**  
   根据受众选择结构模板（见下方）。

4. **生成报告**  
   按结构生成 Markdown 格式报告。用数据和图表说话。  
   标注数据缺口和不确定性。

## 报告结构模板

### 面向技术人员（分析师/数据工程师）
```
1. 背景与目的
2. 数据来源说明（表结构/字段含义/数据范围）
3. 数据处理过程（清洗规则、异常值标准、采样策略）
4. 分析方法及选择理由
5. 关键发现 + 代码片段
6. 局限性与改进建议
```

### 面向业务人员（产品/运营/销售）
```
1. 一句话结论（放在最前面！）
2. 核心指标变化 → 关键数据卡片
3. 分层/分群对比 → 重点群体的差异
4. 趋势图表 + 一句话解读
5. 可执行的业务建议（按优先级排序）
```

### 面向管理层
```
1. 执行摘要（3 句讲清楚结论+影响+建议）
2. 核心指标仪表盘
3. 同比/环比变化 + 原因分析
4. 风险与机会
5. 下一步行动建议
6. 附录（详细数据、方法说明）
```

## 报告写作规范

### 结论先行
每段开头用一句话说结论，再展开细节。业务和管理层受众尤其需要这个。

### 数据说话
- 每个论点必须配具体数据支撑
- 避免笼统表述："显著提升" → 改成 "提升了 23%（从 100 到 123）"
- 能对比就对比：时间对比、分组对比、基准对比

### 标注不确定性
- 统计结果的置信区间、p 值
- 数据质量问题（缺失率、采样偏差）
- 模型预测的误差范围

### 专业术语
- 面向非技术受众时，首次出现的专业术语给出通俗解释
- 例如："p 值（结果由随机因素导致的概率，< 0.05 通常认为统计显著）"

### 报告末尾
必须标注：`*本报告由 AI 辅助生成，建议人工复核关键数据和结论*`

## 如果缺乏先验分析

如果用户没有提供已有的分析代码或图表结果：
- 先调用 describe/stats 工具做简单描述性统计
- 把统计结果整理成 "数据概况" 章节
- 根据字段特征给出 3-5 个值得深入分析的方向建议
- 标注需要补充的具体数据/指标

## 输出格式

```
## <报告标题>

### 1. <章节标题>
<内容——> 每段开头用一句话结论

### 2. <章节标题>
<内容——> 配具体数据

...

## 需补充的数据/信息
- [ ] <数据缺口 1>
- [ ] <数据缺口 2>

---
*本报告由 AI 辅助生成，建议人工复核关键数据和结论*
```
