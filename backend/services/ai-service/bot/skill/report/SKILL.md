# 分析报告生成技能

当用户需要生成数据分析报告时使用此技能。

## 可用工具
- **describe_table** / **describe_csv**: 了解数据来源
- **sample_rows**: 查看数据样例
- **describe_table_stats** / **describe_csv_stats**: 获取统计指标
- 如果要获取的数据信息较多，可以先落盘使用**write_file**工具写到文件中，方便后续查阅
- 如果以上提供的工具无法支撑你的分析主题，可先写出python代码给用户执行，并提示用户给出结果

## 分析流程

1. **明确报告目标** 
   目的是什么？汇报、决策支持、还是技术文档？

2. **收集信息**  
   用户是否已提供相关信息？没有则调用 describe/sample/stats 工具获取数据背景。  
   如果用户已提供分析代码/图表结果，作为报告素材。

3. **确定数据支撑问题核心逻辑**  
   根据数据或提供的信息，写出分析思路，要有逻辑性、专业性。

4. **生成报告**  
   按结构生成 Markdown 格式报告。用数据和图表说话。  
   标注数据缺口和不确定性。

## 报告写作规范

### 数据说话
- 每个论点必须配具体数据支撑
- 避免笼统表述："显著提升" → 改成 "提升了 23%（从 100 到 123）"

### 专业术语
- 将技术术语保持在最低限度，首次出现的专业术语给出通俗解释
- 例如："p 值（结果由随机因素导致的概率，< 0.05 通常认为统计显著）"

### 报告末尾
必须标注：`*本报告由 AI 辅助生成，建议人工复核关键数据和结论*`

### 格式
- 使用 Markdown 格式以提高可读性

## 如果缺乏先验分析
如果用户没有提供已有的分析代码或图表结果：
- 先调用 describe/stats 工具做简单描述性统计
- 把统计结果整理成 "数据概况" 章节
- 根据字段特征给出 3-5 个值得深入分析的方向建议
- 标注需要补充的具体数据/指标

## 报告结构
### 执行摘要
- 简要概述分析目标和关键发现（2-3 句）

### 引言  
- 问题陈述和分析目标
- 数据集描述和范围

### 数据探索
- 数据质量评估（缺失值、异常值等）
- 关键统计信息和分布情况
- 发现的显著模式或异常

### 分析与方法
- 使用的分析方法
- 关键转换和特征工程
- 模型选择理由（如适用）

### 结果与发现
- 主要发现及其支持证据
- 可视化见解和趋势
- 统计显著性和置信度说明

### 结论
- 回答原始问题
- 限制和假设
- 后续工作建议

### 免责声明：`*本报告由 AI 辅助生成，建议人工复核关键数据和结论*`
