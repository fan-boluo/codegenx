# 特征工程技能

当用户需要做机器学习建模前的数据预处理和特征构造时使用此技能。

## 可用工具

- **describe_table** / **describe_csv**: 了解列名和类型
- **sample_rows**: 查看数据样例
- **describe_table_stats** / **describe_csv_stats**: 查看统计分布、缺失情况

## 分析流程

1. **确认目标和任务类型**  
   目标变量是什么？分类/回归/聚类/时间序列？任务类型决定特征处理策略。

2. **了解数据全貌**  
   调用 `describe_*_stats` 获取各列的统计信息、缺失率、分布特征。

3. **分类每列特征类型**  
   按类型分组：数值、类别、时间、文本、缺失严重、常量列。

4. **按类型输出处理建议和代码**  
   每类特征给出 1-2 种推荐处理方案，说明选择理由。
高基数分类字段压缩、异常数值分层离散分箱。
## 处理指南

### 缺失值
| 缺失比例 | 推荐方法 | 条件 |
|---------|---------|------|
| < 5% | 直接删除行 (`dropna`) | 样本量充足 |
| 5%-30% | 填充：数值→中位数，类别→众数/"未知" | 通用场景 |
| 30%-60% | 增加 is_missing 标志列 + 填充 | 缺失可能是信号 |
| > 60% | 删除该列 | 信息量不足 |
| 时间序列 | 前向填充 (ffill) / 线性插值 | 保持时间连续性 |

### 数值特征
- **标准化** (`StandardScaler`)：线性回归、SVM、神经网络、PCA 等需要正态假设的模型
- **归一化** (`MinMaxScaler`)：KNN、K-Means、神经网络等距离敏感的模型
- **对数变换** (`np.log1p`)：偏度 > 1 的长尾分布，变换后更接近正态
- **分箱/离散化** (`pd.cut`)：增强可解释性，捕捉非线性关系
- **异常值**：IQR 法（Q1-1.5×IQR, Q3+1.5×IQR）标记/截尾
- **多项式特征**：生成交互项和平方项，适用于已知存在非线性关系的场景

### 类别特征
- **One-Hot 编码**：类别数 < 20，树模型适用
- **标签编码** (`LabelEncoder`)：类别数 > 20 或有序类别
- **频率编码**：用出现次数替代类别值，处理高基数类别
- **目标编码** (`TargetEncoder`)：用目标变量均值编码（⚠️ 必须 K-Fold 防泄漏）
- **低频合并**：频率 < 1% 的类别合并为 "其他"

### 时间特征
- 提取：年、月、日、星期几（0-6）、小时、季度、是否周末
- 周期性编码：`sin(2π × hour/24)`、`cos(2π × hour/24)` 保留周期信息
- 距离关键日期天数、滑窗聚合统计

### 文本特征
- 基础：文本长度、词数、特殊字符占比
- TF-IDF 或 CountVectorizer（简单文本分类场景）
- 正则匹配生成标志列（是否含手机号、邮箱等）

## 注意事项（必须在代码中体现）

1. **先拆分再处理**：所有 fit（标准化、编码）必须在训练集上做，再 transform 到测试集。绝不能在拆分前 fit！

2. **数据泄露防范**：
   - 目标编码必须 K-Fold：在每折的训练集上算均值，应用到验证集
   - 缺失值填充的中位数要用训练集的中位数填测试集
   - 任何基于目标变量的特征构造在此规则下

3. **高基数类别**（> 50 个不同值）：避免 One-Hot，用频率编码或目标编码

4. **常量列**（全列只有 1 个值）：直接删除，无区分能力
