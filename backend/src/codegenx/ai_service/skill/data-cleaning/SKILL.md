# data-cleaning
整体分为：探查→评估→定策略→执行清洗→高级处理→产出校验六段标准化链路，配套规范产出物与示例代码、验收标准

# 标准化处理全流程
**1. 数据质量探查**
输出字段类型、缺失率、唯一值、分布摘要和样本异常行；配套探查工具：
`describe_table` / `describe_csv`：查看字段名称与数据类型
`sample_rows`：抽样查看原始数据样例
`describe_table_stats` / `describe_csv_stats`：字段统计分布、缺失占比批量分析

**2.数据质量评估**
按字段分类（数值 / 类别 / 时间 / 文本 / ID）分字段定制检测方案
- 异常值检测：IQR 四分位距、Z-Score、业务阈值、机器学习算法四种方式标记异常，先按照简单的来，如果用户提出不合适的疑问可以再换其它方法；
- 缺失值：检查哪几列
- 重复值：检查哪几列
落地：编写检测脚本，批量检出重复、异常、缺失数据，输出质量报告。

**3. 制定清洗策略**
基于评估报告，分维度敲定清洗规则：
- 去除重复：依托业务主键 / 复合主键去重，约定保留规则（最新时间 / 字段完整性最优记录）
- 异常处理：沿用 IQR/Z-Score/ 业务阈值 / 模型识别异常，区分标记、剔除、修正三种处置方式
- 缺失处理：按缺失类型分类（MCAR 完全随机、MAR 随机、MNAR 非随机缺失），选用删除 / 插补 / 保留标记方案
- 数据类型：日期、分类、数值、文本、布尔字段统一格式，输出字段映射对照表
- 离散化分箱：连续数值分箱、分级、二值化，提升业务可解释性与模型稳定性
- 多源冲突：比对多源字段定义、统计时间、计量单位、统计口径，制定数据源优先级与合并规则
策略定稿：汇总评估结果与清洗细则，和用户确认，迭代生成最终完整清洗方案。

**4. 执行核心清洗**
编写可复用清洗 Python 脚本，全覆盖：缺失处理、异常处置、重复去重、类型转换、编码映射、业务规则修正；
脚本内置数据校验函数，清洗前后分别调用，量化对比数据质量变化。

**5. 处理高级问题**
多源 / 多表数据对齐、字段口径冲突消解；如果有的话

**6. 产出结果与校验**
全量校验清洗后数据完整性、字段一致性、数据合规性。
**标准化产出内容规范**
- 可复用清洗脚本：模块化封装，支持重复调用
- 清洗后数据文件：无论源数据是 CSV / 数据库表，统一输出.csv；
  约束：原始数据＞50 万行时不自动运行清洗，交付脚本提示用户自行执行
- 清洗总结报告：原始数据质量概述、分步清洗执行明细、清洗前后指标对比
